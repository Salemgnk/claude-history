# claude-history en terminal : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `claude-history` sans argument ouvre un sélecteur `fzf` de toutes les conversations Claude Code, avec aperçu, recherche plein texte et reprise par `Entrée`.

**Architecture:** Un seul script Python. Les fonctions de lecture existantes (`iter_records`, `summarize`, `sessions`, cache) sont réutilisées telles quelles. On ajoute un rendu texte, une recherche partagée entre web et terminal, et un `main()` à sous-commandes. `fzf` rappelle le script lui-même pour la liste, l'aperçu et la bascule de mode.

**Tech Stack:** Python 3.14 (bibliothèque standard uniquement), fzf 0.74, ripgrep 15 (facultatif), less. Tests avec `unittest`.

**Spec:** `~/.local/share/claude-history/docs/2026-11-18-cli-design.md`

## Global Constraints

- Fichier modifié : `~/.local/bin/claude-history` uniquement. Tests dans `~/.local/share/claude-history/tests/test_cli.py`.
- Lecture seule sur `~/.claude/projects` : aucune écriture, aucune suppression.
- Aucune dépendance Python hors bibliothèque standard.
- Le cache `~/.cache/claude-history/index.json` garde son format actuel.
- L'interface web doit rester identique, accessible par `claude-history web [port] [--no-open]`.
- Tous les textes affichés sont en français, avec accents, sans tiret cadratin.
- Pas de dépôt git ici : aucune étape de commit. La sauvegarde de l'original tient lieu de point de retour.
- Les conversations de sous-agents (`isSidechain`) et les messages `isMeta` ne sont jamais affichés ni cherchés.

## Review Focus

1. Titre ou premier message contenant une tabulation, un retour à la ligne ou une séquence ANSI : la ligne `fzf` doit rester sur une ligne avec exactement ses champs. (Tâche 1, `test_list_line_is_sanitized`)
2. Recherche contenant un guillemet ou une barre oblique inverse, écrits `\"` et `\\` dans le fichier brut : la conversation doit être trouvée. (Tâche 2, `test_search_query_with_quote`)
3. Dossier d'origine supprimé, ou `claude` absent du PATH : afficher la commande de reprise et sortir avec le code 1, sans trace d'erreur Python. (Tâche 3, `test_resume_missing_dir`)
4. Aperçu d'une très grosse conversation interrompu par `fzf` : l'écriture est faite au fil de l'eau et `BrokenPipeError` est avalée. (Tâche 1, `test_write_text_survives_broken_pipe`)
5. Historique vide ou `~/.claude/projects` absent, et `fzf` absent : message clair en français, code de sortie 1, pas de trace d'erreur. (Tâche 3, `test_pick_without_fzf`, `test_list_empty_root`)

### Task 3: Sous-commandes, sélecteur fzf, reprise

**Files:**
- Modify: `~/.local/bin/claude-history` (docstring d'usage, `main`, nouvelles fonctions)
- Test: `~/.local/share/claude-history/tests/test_cli.py`

**Interfaces:**
- Consumes: `list_lines`, `search_lines`, `write_text`, `write_hits` ; le `main()` actuel devient `serve(port: int, open_browser: bool)`.
- Produces:
  - `main(argv: list[str] | None = None) -> int`, appelé par `sys.exit(main())`. Charge le cache avant toute commande.
  - `resume_command(info: dict) -> str` : `cd <cwd> && claude --resume <id>`, `cwd` protégé par `shlex.quote`.
  - `resume(info: dict) -> int` : si `cwd` est un dossier et `claude` est dans le PATH, `os.chdir` puis `os.execvp("claude", ["claude", "--resume", id])` ; sinon écrit la raison et `resume_command(info)` sur stderr et renvoie 1.
  - `toggle_action(prompt: str, me: str) -> str` : chaîne d'actions `fzf` pour basculer de mode.
  - `fzf_args(me: str) -> list[str]` et `pick() -> int`.

Table des commandes :

| Arguments | Effet |
|---|---|
| (aucun) | `pick()` |
| `list` | écrit `list_lines()` sur stdout |
| `search <mots...>` | écrit `search_lines(" ".join(mots))` |
| `preview <projet> <id> [requête]` | si `FZF_PROMPT` commence par `texte` et que la requête fait 2 caractères ou plus, `write_hits` ; sinon `write_text` |
| `show <projet> <id>` | `write_text` dans `less -R` si stdout est un terminal, sinon sur stdout |
| `toggle` | écrit `toggle_action(os.environ.get("FZF_PROMPT", ""), me)` |
| `web [port] [--no-open]` | `serve` |
| `<nombre> [--no-open]` | `serve` sur ce port (ancienne syntaxe) |
| `-h`, `--help` | affiche la docstring, code 0 |
| autre chose | docstring sur stderr, code 2 |

`<projet>` et `<id>` sont validés par l'expression `SAFE` existante ; fichier introuvable : message « Cette conversation n'existe plus sur le disque. », code 1. `list`, `search`, `preview` et `show` avalent `BrokenPipeError`.

`me` est `shlex.quote(sys.executable) + " " + shlex.quote(os.path.abspath(__file__))`.

Options `fzf` :

```
--ansi --delimiter=\t --with-nth=3.. --layout=reverse --tiebreak=index
--prompt=titre>
--header=Entrée reprendre · Ctrl-F chercher dans les messages · Ctrl-O lire · Échap quitter
--preview=<me> preview {1} {2} {q}
--preview-window=right,55%,wrap
--bind=start:unbind(change)
--bind=change:reload:<me> search {q}
--bind=ctrl-f:transform:<me> toggle
--bind=ctrl-o:execute:<me> show {1} {2}
```

Les invites sont exactement `titre> ` et `texte> ` (avec l'espace finale). `toggle_action` :
- invite ne commençant pas par `texte` : `change-prompt(texte> )+disable-search+rebind(change)+reload(<me> search {q})`
- sinon : `change-prompt(titre> )+enable-search+unbind(change)+reload(<me> list)`

`pick()` lance `fzf` avec `list_lines()` sur son entrée standard, lit la ligne choisie sur sa sortie, retrouve la session par `summarize` et appelle `resume`. Code de sortie 130 ou 1 de `fzf` (abandon, rien choisi) : renvoyer 0 sans rien afficher. `fzf` absent : « fzf est introuvable. Installe-le, ou lance : claude-history web », code 1. Aucune conversation : « Aucune conversation dans ~/.claude/projects. », code 1.

Docstring d'usage, en tête du fichier :

```
claude-history : retrouver et reprendre une conversation Claude Code.

Usage :
  claude-history                       sélecteur interactif (fzf)
  claude-history list                  liste des conversations
  claude-history search <mots>         conversations dont les messages contiennent <mots>
  claude-history show <projet> <id>    lire une conversation
  claude-history web [port] [--no-open]  interface navigateur sur 127.0.0.1
```

```python
class TestCli(Case):
    def run_main(self, *argv):
        out, err = io.StringIO(), io.StringIO()
        with contextlib.redirect_stdout(out), contextlib.redirect_stderr(err):
            code = mod.main(list(argv))
        return code, out.getvalue(), err.getvalue()

    def test_list_and_search_commands(self):
        code, out, _ = self.run_main("list")
        self.assertEqual((code, len(out.splitlines())), (0, 2))
        code, out, _ = self.run_main("search", "ping", "pas")
        self.assertEqual((code, out.split("\t")[1]), (0, "aaa"))

    def test_list_empty_root(self):
        mod.ROOT = self.root / "absent"
        mod.CACHE.clear()
        self.assertEqual(self.run_main("list")[:2], (0, ""))
        code, _, err = self.run_main()
        self.assertEqual(code, 1)
        self.assertIn("Aucune conversation", err)

    def test_preview_modes(self):
        with mock.patch.dict(os.environ, {"FZF_PROMPT": "titre> "}):
            self.assertIn("1 action : Bash", self.run_main("preview", "proj-a", "aaa", "forward")[1])
        with mock.patch.dict(os.environ, {"FZF_PROMPT": "texte> "}):
            out = self.run_main("preview", "proj-a", "aaa", "forward")[1]
        self.assertIn("\033[7mforward", out)
        self.assertNotIn("1 action", out)

    def test_show_rejects_bad_ids(self):
        self.assertEqual(self.run_main("show", "../etc", "passwd")[0], 1)
        code, _, err = self.run_main("show", "proj-a", "zzz")
        self.assertEqual(code, 1)
        self.assertIn("n'existe plus", err)

    def test_help_and_unknown(self):
        self.assertEqual(self.run_main("--help")[0], 0)
        self.assertEqual(self.run_main("nimporte")[0], 2)

    def test_web_routing(self):
        with mock.patch.object(mod, "serve") as serve:
            mod.main(["8788", "--no-open"])
            mod.main(["web"])
        self.assertEqual(serve.call_args_list, [mock.call(8788, False), mock.call(8787, True)])

    def test_toggle_action(self):
        to_text = mod.toggle_action("titre> ", "ME")
        self.assertIn("change-prompt(texte> )", to_text)
        self.assertIn("reload(ME search {q})", to_text)
        back = mod.toggle_action("texte> ", "ME")
        self.assertIn("change-prompt(titre> )", back)
        self.assertIn("reload(ME list)", back)

    def test_resume_command_quotes(self):

        self.assertEqual(mod.resume_command(info), "cd '/tmp/vpn maison' && claude --resume aaa")

    def test_resume_missing_dir(self):
```
